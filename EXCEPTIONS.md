# Exceptions

Words that must not be blocked, or must only be blocked in a narrower form,
because they have a legitimate meaning in WoW chat. Keep `BlockList.lua` in
line with this file. `tools/review.py` also gives this file to the reviewer, so
a player using one of these terms in its WoW sense isn't held against them.

## Exceptions

### `RFK`
- **Do not block:** `RFK` (bare).
- **Why:** Common acronym for Razorfen Kraul, a dungeon in WoW (for example "LF healer RFK").
